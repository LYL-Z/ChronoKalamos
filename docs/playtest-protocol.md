# ChronoKalamos 阶段14小规模公开测试协议

## 1. 范围

测试对象仅为 `tang-changan-742`。发布版本为 `36`，内容版本为 `11.0.0`，场景版本为 `1.0.0`。支付、短信、微信、QQ、Passkey 与第二历史场景均不在测试范围。

本测试不是商业完成声明。它只检验十分钟垂直切片的可理解性、连续性、恢复能力与证据边界。

## 2. 样本与招募

- 目标样本为 8—20 名自愿参与者。
- 三种出身线各至少 2 人。
- 不向未成年人定向招募。
- 不支付报酬，不以付费能力影响参与。
- 至少一名与项目无经济隶属的历史研究者独立审阅。

系统不会自动发送邀请。项目负责人须自行将 `/playtest` 链接发给真实参与者。历史审阅者必须留下可核身份、审阅范围、日期、决定、证据文件与利益冲突声明。

## 3. 同意与退出

参与者必须先阅读 `/playtest` 的采集边界，再主动加入。既有游戏行为不会回填。退出会删除本次同意记录及全部关联事件。游戏存档不受影响。

游客身份只存在于当前浏览器。清除浏览器数据、退出或换设备后无法恢复。此风险在同意前显示。

## 4. 允许字段

允许字段仅包括版本号、固定事件名、出身编号、事件编号、选择编号、输入种类、回合号、耗时、规范化错误码、退出点、恢复路径、来源数量和三级史料标签。

禁止字段包括自由输入、叙事正文、邮箱、手机号、IP 地址、User-Agent、浏览器指纹、图片、付款信息、Cookie、模型提示、模型原始响应和访问令牌。

测试数据保留 30 天。维护命令默认为只读预演：

```powershell
npm run playtest:cleanup
npm run playtest:cleanup -- --apply
```

## 5. 预注册指标

### 体验门槛

- 首次选择耗时从首个 `session_started` 到其后的首个 `choice_submitted` 计算，中位数不高于 90 秒。
- 首回合完成率不低于 80%。
- 三回合完成率不低于 60%。
- 五回合完成率不低于 40%。
- 回合失败率不高于 5%。
- 回合延迟 P95 不高于 30 秒。

### 可信度门槛

- 已提交回合的来源覆盖率为 100%。
- 跨用户读取事故为 0。
- 非法状态提交为 0。
- 至少一份独立且可核验的历史审阅通过，且没有未解决的阻断项。

完成率分母是所有主动加入该版本测试的人。未开始者因此保留为流失，不从分母剔除。指标必须绑定发布、内容和场景版本。样本不足、分母为零或审阅缺失时，结论固定为 `insufficient_evidence`。少于 3 人的分支单元不得公开。

## 6. 分析与停止规则

分析命令只读取允许字段，不查询 Auth 邮箱、手机号或用户元数据：

```powershell
npm run playtest:report
npm run playtest:report -- --require-pass
```

只有体验门槛与可信度门槛同时通过，才可进入商业级讨论。未通过时只修复当前长安切片，不扩第二场景，不启用支付。
