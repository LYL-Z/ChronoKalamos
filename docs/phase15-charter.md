# ChronoKalamos 阶段15章程：档案式社会模拟核心

## 范围

阶段15只升级 742 年长安的现有三种出身。它不增加第二场景，也不开放品官、世族、宗室或帝王玩法。

对标《皇帝成长计划》只取四项可验证机制：

- 高频入口常驻；
- 核心状态常驻；
- 回合结算可读；
- 复杂系统通过一致面板组织。

不复制其美术、文本、地图或帝王系统。当前项目没有支持帝王玩法的全国数据、官僚模型、军事模型和来源台账。若直接加入，只会得到不可验证的界面承诺。

## 决策

### 三行动日循环

每个叙事日有三个行动位。每次行动仍是一个独立的幂等回合。

第三次行动在同一数据库事务中完成日结：

1. 写入编辑规则决定的状态变化；
2. 将时间推进到次日 06:00；
3. 将精力恢复到 `3/3`；
4. 不触发第二次模型调用；
5. 不创建第二个 `clientTurnId`。

这避免了“行动提交成功、日结提交失败”的半状态。

### 系统入口

七个入口均读取现有权威状态：

| 入口 | 权威来源 |
|---|---|
| 地图 | 已发布 `MapFeature` 和当前事件 |
| 属性 | `skills`、`health`、`energy`、`morale` |
| 背包 | `items` |
| 关系 | `relationships` 与 `relationshipMemories` |
| 营生 / 公务 | `occupation`、当前事件、三行动日循环 |
| 任务 | `quests`、`risks`、`riskClocks` |
| 家户 | 出身、家户声望和有限角色资料 |

空数据必须显示真实空状态。不得用示例物品、示例关系或虚构成就填满面板。

## 史料边界

- 地图仍只有 8 个证据地点。
- 108 坊是后续证据索引目标，不是当前精确 GIS。
- 胥吏不等于品官。
- 商户和工匠仍属平民家户切片。
- 家户面板不暗示婚姻、生育、宗族和跨代系统已经存在。

## 退出条件

- 旧存档无需迁移即可补齐精力和士气默认值。
- 三次行动只产生三次回合写入。
- 七个入口全部有真实数据来源或明确空状态。
- 1440 × 1000 与 390 × 844 均无页面级横向溢出。
- 键盘快捷键不在输入框内劫持按键。
- 空格只聚焦行动卷宗，不自动提交。
- axe 无障碍检查无违规。
- 项目级 lint、类型检查、单测、契约测试、E2E 和构建通过。
