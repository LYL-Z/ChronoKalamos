## 渲染边界

- 规则、状态、证据和事务仍由服务端与 Supabase 管理。
- 电影化画面只读取当前事件，不反向修改 `WorldState`。
- 文字、字幕、选项和声音控制继续使用DOM。
- 不引入Unity运行时，也不把网站迁移到第二套引擎。
- 当前仓库没有 `Assets/`、`Packages/manifest.json` 或 `ProjectSettings/ProjectVersion.txt`，因此Unity构建状态为 `Not validated / not applicable`。

## 镜头语言

三条出身线共享四种镜头：

1. `threshold`：门槛与社会边界。
2. `tabletop`：账纸、量具、文书和可复核痕迹。
3. `corridor`：时限、递送和责任范围。
4. `close-detail`：印记、磨损、空白与证据缺口。

画面不得制造精确考古复原。文字、印记和官署细节必须保持不可辨识或明确虚构。强动态只用于事件进入、风险变化和章节收束。所有持续移动受产品低动态开关和 `prefers-reduced-motion` 控制。

## 声音与台词

- 27个事件各有一条人物台词。
- 台词全部标 `叙事虚构`。
- 字幕常显，声音默认关闭。
- 第一版只调用用户设备的 `SpeechSynthesis`。
- 界面必须显示“现代普通话设备合成音”。
- 不克隆真人声音，不声称复原中古汉语或粟特语。
- 场景声目前只作为导演说明，不自动播放，也不附带版权不明的音频。
