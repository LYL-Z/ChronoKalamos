## Advisor 边界

游客是 Supabase Auth 匿名用户，但在数据库中使用 `authenticated` 角色。阶段14表仍要求 `auth.uid() = owner_id`，浏览器没有事件插入权限。Advisor 的匿名访问警告因此属于已接受的游客体验边界，不代表公开可读。

泄露密码保护仍未开启。Supabase 当前把该能力限制在 Pro 及以上方案。免费公开测试继续使用邮箱无密码入口与 TOTP，不把该项写成已完成。
