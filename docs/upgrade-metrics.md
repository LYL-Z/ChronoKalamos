# 精品垂直切片指标

以下均为目标值，不代表当前生产现状。

## 体验指标

- 首次看到第一个可理解选择：不超过90秒。
- 三种出身均可完成前三回合。
- 五回合完成率在小规模测试中达到预先登记的目标阈值。
- 用户可以在回合结束看到选择、状态变化、来源和未解决风险。
- 移动端390px宽度下不出现横向滚动和不可操作控件。

## 可信度指标

- 事实性叙事100%包含来源编号。
- `史料记载`声明100%映射到已发布来源。
- `合理重建`和`叙事虚构`不得显示为史料原文。
- 0次未经规则许可的状态变化。
- 0次跨用户读取存档、图片或回合。

## 可靠性指标

- 重复 `clientTurnId` 不重复调用模型、不重复推进时间。
- 模型超时、流断开和校验失败均不提交状态。
- 回合错误能回到可重试界面。
- 公开测试版本可以通过Sites保存版本回滚。

## 观测字段

只记录完成漏斗所需的最小数据：版本号、内容版本、场景、出身、回合编号、耗时、结果、错误码和退出位置。不得记录原始提示词、私人图片或不必要的身份信息。
