## 本轮额外修复

`vinext@0.0.50` 的Node生产服务器在Windows上把磁盘分隔符写入静态资源缓存键，导致HTML为200而 `/assets/*` 为404。项目增加了幂等的安装期兼容补丁，并把生产静态资源烟雾测试纳入 `npm test`。补丁在上游代码结构变化时会直接失败，避免静默修改未知版本。

## 未验证与边界

- `.env.test` 未提供服务端 Supabase Secret。因此，本轮 live 测试没有通过服务密钥执行完整的真实 DeepSeek 提交。
- 嵌入式浏览器完成了桌面可见检查。其视口能力未实际切换到390px，所以本轮没有新增移动端人工截图证据。390px断点仍由既有自动化回归覆盖。
- Supabase Advisor 仍会报告匿名访问策略。它们服务于匿名已认证游客，并受所有者条件约束，不能简单删除。
- 泄露密码保护受当前Supabase Free计划限制，不能宣称已开启。
- 新增索引刚建立时可能被Advisor标记为未使用。现阶段不应据此删除。
- 93项确定性评测不包含真实供应商延迟分布，也不能替代历史准确性审阅。

进入阶段 11 前，至少应补做一次带服务端测试密钥的真实回合提交，并保留失败不提交和重复请求证据。内容发布仍需外部历史学者审阅。
