## 当前阶段边界

当前代码已包含 Supabase 匿名身份、邮箱升级、不会覆盖既有状态的幂等存档、RLS 迁移和私有上传适配。未提供 Supabase 项目配置时，界面会明确降级为开发模拟器。AI、真实地图、支付和第三方登录仍未接入。

## 0～3阶段唯一外部阻塞

需要一个已应用迁移的 Supabase 测试项目，并提供测试用 URL 与 publishable key，才能运行 `npm run test:supabase:live`。该测试不接受 service-role key，也不会把任何密钥写入仓库。完成这项实测后，阶段3才可标记为完成；在此之前不得宣称“用户隔离已通过”。
