# 阶段11外部历史审阅包

本文件不是审阅通过证明。当前状态是 `pending`。

## 候选规模

- 3条章节线。
- 27个事件。
- 81个受限选择。
- 12名命名NPC。
- 9组交互物品。
- 6个风险时钟。
- 27条带字幕的人物台词，全部标为叙事虚构。
- 27个候选镜头合同，全部默认静音并禁止声称唐代语音复原。
- 100条事件—来源引用链接；它们来自18条独立书目，不得写成“100部来源”。
- 40条总声明，其中27条为阶段11候选声明。
- 8个总地图要素，其中3个为阶段11候选要素。
- 18条来源记录。

公开测试游戏使用阶段11的27个事件。它们仍为 `provisional`，并持续显示“未经外部历史学家认证”的提示。公开运行不构成历史审阅通过。

## 审阅者最低条件

审阅者必须满足一项：

- 有隋唐史、唐代城市史、社会经济史、中古中外交流史或出土文书研究的可核学术经历。
- 有相关博物馆、考古机构或高校的正式研究职责。
- 有可核的同行评议成果，并能说明与本内容包的直接关系。

项目成员、AI工具、检索插件和匿名测试用户不能替代外部历史审阅者。

## 审阅任务

审阅者应逐项给出 `通过`、`降级`、`改写` 或 `删除`：

1. C-742-007 至 C-RISK-L01的27条候选声明。
2. M-006 至 M-008的时间、方位、不确定性和表述。
3. 三条章节的制度外推。
4. 12名NPC的姓名、角色功能和刻板印象风险。
5. 27个事件的时代错置、职业错置和不当确定性。
6. 每个“史料记载”或“合理重建”标签是否与来源强度相配。
7. S-003、S-008、S-015、S-016、S-018的具体页码或卷次。
8. 27条人物台词是否制造身份刻板印象、现代价值投射或不必要的确定性。
9. 100条事件—来源链接的三种范围标签是否准确：事件背景、声明支持、场景地点。

## 决定规则

只有以下条件同时成立，才允许把条目升级为 `reviewed` 或 `published`，并宣称完成外部历史审阅：

- 至少一名合格外部审阅者提交签名或可核的机构化审阅记录。
- `publication-gate.json` 中存在真实审阅者记录。
- 审阅决定是 `approved`。
- 所有要求修改的条目已产生新内容版本。
- 内容校验、类型检查、单元测试、契约测试和Supabase隔离测试全部通过。
- 发布迁移只复制经批准条目，不直接修改原候选审阅记录。

## 当前阻塞

当前没有可核的签名文件、机构化审阅记录或证据文件摘要。聊天中输入的姓名、机构、决定与“签章”字样不能替代原始证据。因此阶段11可以作为“未经外部审阅的公开测试版”运行，但不能声称“历史认证完成”“学者批准”或“机构背书”。

240项Phase 11评测已经变为可执行测试并通过专项运行。该结果只证明数据合同、规则边界和对抗输入门禁，不证明历史判断正确，也不替代外部审阅。

恢复认证并正式记录前必须完成两项核验：

1. 提供签名PDF、签名图片或可核机构记录，并计算SHA-256；仓库只保存摘要、范围、日期、决定和不含私人联系方式的证据路径。
2. 为S-003、S-008、S-015、S-016、S-018及审阅中使用的新来源补齐版本、页码、卷次或稳定条目标识。仅写“全篇”“相关卷次”不符合发布门槛。

证据文件放入本地 `review-evidence/`。该目录不会进入Git或Sites包。运行：

```powershell
npm run review:verify:phase11 -- ".\review-evidence\signed-review.pdf"
```

脚本输出文件大小与SHA-256。它只验证文件完整性，不验证签名人身份。身份仍需通过机构邮件、机构公示或其他独立渠道核验。
