# Sand & Cinnabar 视觉规范

## 方向结论

砂纸、朱砂、靛蓝与黄铜构成一种“档案被反复翻阅”的界面。地图是主画布，时间轴负责锚定年份，登录纸页负责把访客引入第一步。

## 令牌

| 用途 | 值 |
| --- | --- |
| Sand background | `#DDC69B` |
| Paper surface | `#F5EAD0` |
| Ink | `#18243F` |
| Ink secondary | `#4D5A77` |
| Cinnabar | `#A33D2E` |
| Brass | `#A47E42` |

## 排版

- 中文叙事使用 Georgia 与系统宋体回退，保持历史文献的节奏。
- 元数据、来源编号和状态使用系统等宽字体。
- 字号走根字号角色，使设置里的「较大」真正放大：叙事 `--type-body`（0.8125rem）、说明与出处 `--type-caption`（0.75rem）、目录标签 `--type-kicker`（0.6875rem）、地图印记 `--type-hud`（0.625rem）。不要再给可读正文写死 7–10px。
- 动态玻璃不铺满页面，只用于浮层和状态卡。

## 信息层级

1. 地点与年份。
2. 史料边界说明。
3. 游客或邮箱入口。
4. 三种出身选择。

页面不使用伪登录按钮，不使用 emoji 作为图标，也不把地图原型宣传为考证地图。

## 印记

界面左上角菱形印里的 `ZW` 是装饰性朱文印：朱砂阳文，不是 ChronoKalamos 的拉丁缩写，也不代表虚构机构。印记对屏幕阅读器隐藏；品牌链接的可访问名称仍是产品首页。
