# Sand & Cinnabar 视觉规范

## 方向结论

砂纸、朱砂、靛蓝与黄铜构成一种“档案被反复翻阅”的界面。地图是主画布，时间轴负责锚定年份，登录纸页负责把访客引入第一步。

## 令牌

| 用途 | 值 |
| --- | --- |
| Sand background | `#DDC69B` |
| Paper surface | `#F5EAD0` |
| Ink | `#18243F` |
| Ink secondary | `#4D5A77` |
| Cinnabar | `#A33D2E` |
| Brass | `#A47E42` |

## 排版

- 中文叙事使用 Georgia 与系统宋体回退，保持历史文献的节奏。
- 元数据、来源编号和状态使用系统等宽字体。
- 动态玻璃不铺满页面，只用于浮层和状态卡。

## 信息层级

1. 地点与年份。
2. 史料边界说明。
3. 游客或邮箱入口。
4. 三种出身选择。

页面不使用伪登录按钮，不使用 emoji 作为图标，也不把地图原型宣传为考证地图。
