# 阶段9上手规范

## 用户路径

1. 访客看到地图、证据边界和三种出身。
2. 点击“新开始”或“以游客身份开始”。
3. 选择出身，并填写姓名、性别和一个性格倾向。
4. 系统创建或恢复本人存档，再通过受限RPC保存角色资料。
5. 游戏界面展示个人化开场、三个首回合选择和提交边界。
6. 回合提交后展示回顾卡、状态版本和来源台账。

## 数据边界

- 姓名最长40字符。
- 性别只接受 `unspecified`、`female`、`male`、`nonbinary`。
- 性格只接受谨慎、好奇、克制、外向。
- 角色资料RPC只允许本人更新本人存档。
- 角色资料不得替换出身、场景、世界状态或社会身份。

## 失败处理

- 未配置Supabase时不创建权威存档。
- 未填写姓名时不能提交角色设定。
- RPC失败时不进入游戏界面。
- 回合失败时继续显示“本回合未提交”。
- 图片叙事能力未启用，界面只显示筹备中说明。
