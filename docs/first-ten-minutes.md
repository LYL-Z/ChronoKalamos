# 首十分钟内容骨架

## 共同节奏

| 时间 | 用户应理解的内容 | 产品反馈 |
| --- | --- | --- |
| 0—30秒 | 这是742年长安的有限历史切片 | 地图、时间和史料边界可见 |
| 30—90秒 | 自己的出身与有限自定义范围 | 姓名、性别、性格和出身设定 |
| 1—3分钟 | 第一项行动为何可选 | 三个带意图和风险的选择 |
| 3—7分钟 | 选择会改变时间、状态和关系 | 世界状态、来源与回顾卡 |
| 7—10分钟 | 尚未解决的风险会进入下一回合 | 风险、任务和下一次选择 |

## 三种开场

### 西市商户家庭

从账纸、市场通行和多语交易进入第一回合。首要问题是确认记录与交易之间是否一致。

### 工匠家庭学徒

从材料、工序和交付期限进入第一回合。首要问题是平衡师长要求、生产责任和市场需求。

### 京兆基层吏员家庭

从待抄文书、地名核对和递送范围进入第一回合。首要问题是避免含混记录造成行政风险。

这些开场是叙事入口，不是史料原文。具体历史表述仍必须引用已发布来源。
