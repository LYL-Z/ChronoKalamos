# 阶段 4：742 年长安史料方法

## 研究对象与边界

本阶段只处理一座城市和一个年份：唐代长安，公元 742 年，天宝元年。内容包不声称复原“完整的唐代社会”，也不声称能够定位每个店铺、家庭或人物。

地图是证据索引，不是考古测绘图。几何使用 `schematic-changan-grid-v1` 坐标系。它表达相对位置和证据关系，不提供现代 GIS 意义上的精确经纬度。每个地图要素都展示有效时间、时间精度、来源、许可和不确定性。

## 三级标签

### 史料记载

存在可以定位的古籍条目或明确的史料记录。文本只陈述来源能够支撑的范围。年号、京兆府沿革等制度性条目属于这一层。史料记载不等于角色存在，也不等于事件发生在玩家身上。

### 合理重建

多个来源共同支持一个社会或空间背景，但无法证明全部细节。西市的商业背景、坊区网格和城门制度属于这一层。重建必须写出推断边界，不得用确定语气遮蔽不确定性。

### 叙事虚构

用于让游戏继续运行的姓名、家庭、账簿、对话、任务和结局。虚构条目不伪装成史料人物，不挂接 CBDB 记录，也不使用“据史料”措辞。虚构条目可以与史料背景相邻，但必须保留独立标签。

## 证据链

1. 先登记来源，再写 claim。每个 `史料记载` 或 `合理重建` 条目至少有一个来源编号。
2. 来源只保存书目、定位和许可信息。项目不复制受版权或商业授权限制的正文、图版或人物数据库。
3. `HistoricalClaim.source_ids` 与 `historical_claim_sources` 共同记录来源关系。数据库只向客户端公开 `published = true` 的行。
4. 事实文本与叙事连接句分离。事实文本不能替虚构人物背书。
5. 地图要素使用有效起止年份。无法确定具体年份时使用 `decade` 或 `century` 精度，不伪造日期。

## 三种出身的证据边界

- O-01 西市粟特商户家庭后辈：粟特商贸网络与长安社群是合理重建；个人姓名、族谱、店铺和账簿是叙事虚构。
- O-02 长安工匠家庭学徒：手工业、官署工艺与城市交易构成合理重建；师徒关系、材料清单和工坊冲突是叙事虚构。
- O-03 京兆基层吏员家庭成员：京兆府的制度位置是史料记载；基层文书环境是合理重建；家庭成员、住址和履历是叙事虚构。

## 发布闸门

`npm run content:validate` 必须满足以下条件：

- 内容包的 scenario ID 是 `tang-changan-742`，年份是 742。
- 三种出身都已发布，且引用存在的 claim 与 source ID。
- 所有已发布的事实性 claim 都有来源。
- 叙事虚构 claim 不伪装为有来源的事实。
- 所有地图要素覆盖 742 年，含不确定性说明、许可代码和归属文本。
- CHGIS 与 CBDB 只作为许可红线记录，不能被任何已发布 claim 或地图要素引用。

脚本通过不等于历史学审稿完成。上线前仍需由熟悉中古中国史与历史 GIS 的研究者逐条复核原始定位、译文和地图示意。
