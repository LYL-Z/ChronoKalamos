# Phase 16 章程：档案式成长闭环

## 结论

Phase 16 不扩第二场景，也不伪造七阶层完成度。它把现有 27 个事件转化为更清楚的短期目标、回合反馈、图鉴和成就闭环。当前仍只开放 742 年长安与三种出身。

《皇帝成长计划2》的官方产品说明强调单局养成、随机事件、人物收集和国家治理。ChronoKalamos 只借鉴“持续目标—回合决策—可见反馈—再次规划”的节奏。它不复制对方界面、文案、素材、卡牌或数值系统。

## 本阶段交付

| 交付 | 状态 | 权威来源 |
|---|---|---|
| 10 日模拟旬期 | 已实现 | 从 `WorldState.time.turn` 派生，不新增时钟 |
| 三项出身目标 | 已实现 | 从已提交事件、声望和关系记忆派生 |

| 数字键与全局快捷键 | 已实现 | 只聚焦，不自动提交权威回合 |
| 成人内容服务端门禁 | 已实现 | 默认关闭；不连接公开 UI 或内容 |

## 不在本阶段宣称完成

- 108 坊精确复原；
- 关内道与大唐全境可操作地图；
- 品官、世族、宗室和帝王可玩身份；
- 朝政、军事、后宫、婚育和跨代继承；
- 200 件物品与 50 个结局；
- 18+ 叙事或露骨内容；
- 外部历史学家认证。

这些项目需要独立的史料台账、规则模型、内容评测和发布审查。当前页面不得用未解锁卡片假装已经交付。

## 退出条件

1. 旬期、目标和成就只由权威世界状态派生。
2. 回合结算显示所有可见数值变化。
3. 图鉴不展示未发布来源。
4. 快捷键不绕过确认，不产生重复提交。
5. 公开站继续标明 `provisional` 与历史审阅待定。
6. 成人内容默认关闭，且缺任一门禁即不可发布。
7. lint、类型检查、单元测试、契约测试、E2E 与构建通过。
