# Localization status

Public language status must be described without implying content completeness.

| Language | Interface | Historical content | Public wording |
|---|---|---|---|
| Chinese | internally checked | internally checked; external historian review pending | primary language |
| English | usable support layer | boundary notices and partial supporting content | supporting language |
| French | test interface | incomplete | interface translation only |
| Greek | test interface | incomplete | interface translation only |
| Russian | test interface | incomplete | interface translation only |

French, Greek, and Russian must display `仅界面翻译` in settings. They may not be described as full historical translations.

Language selection changes interface preference only. It does not alter source texts, classifications, publication status, or AI evaluation.

The preference is stored locally under `chronokalamos-locale`. No language preference is written to the profile in Phase 12.
