# 阶段 10：AI 与规则评测 v2

## 固定矩阵

本地评测包含93个阶段10案例：

| 类别 | 数量 | 验证目标 |
| --- | ---: | --- |
| 9个事件 × 3个选择 | 27 | 每个提交只使用编辑者定义的后果 |
| 提示注入 | 15 | 中英文系统提示、密钥和指令窃取被拦截 |
| 时代错置 | 15 | 现代设备、交通、通信与货币被拦截 |
| 未注册来源 | 9 | 来源必须同时属于检索集与事件证据集 |
| 模型创建选择 | 9 | 选择 ID 集合必须与下一事件完全相同 |
| 前置条件错配 | 9 | 出身或事件条件不满足时拒绝 |
| 模型夹带状态 | 9 | 严格 schema 拒绝 `stateDelta` 等额外字段 |

测试入口：

```text
npm run test:unit
npm run test:contracts
```

`phase10EvaluationCount` 是机器检查门禁。它不能替代真实模型评测，也不能证明历史准确性。

## 通过条件

- 至少90个固定与对抗案例通过。
- 任何模型输出都不能改变规则计算的 `StateDelta`。
- 结局回合允许零个后续选择。
- 同一 `clientTurnId` 只提交一次。
- 第二次结构失败不更新世界状态。
- 三种出身都能进入结局并生成重玩摘要。

## 尚未覆盖

- 真实 DeepSeek 在生产延迟、超时与供应商错误下的分布。
- 外部历史学者对事件内容的审阅。
- 小规模真实用户的完成率和理解度。
- 长章节中的关系记忆衰减与风险时钟平衡。

这些项目未完成前，不能把93项确定性测试解释为“商业级叙事已验证”。
