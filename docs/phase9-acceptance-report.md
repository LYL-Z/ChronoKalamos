## 可重复命令

该命令会创建一次性匿名身份、调用真实生产 AI 和数据库，并删除测试存档。它会产生
少量 DeepSeek 调用成本，因此默认拒绝执行。

```powershell
$env:PHASE9_PRODUCTION_ACCEPTANCE='1'
npm run test:phase9:production
```

可只验收一个出身：

```powershell
$env:PHASE9_PRODUCTION_ACCEPTANCE='1'
npm run test:phase9:production -- --origin=merchant
```

## 未被本报告证明的事项

- 这不是历史学者外部审阅。
- 三名自动化身份不能替代真实用户可用性测试。
- 14—20秒的单回合延迟仍需阶段14按 P50、P95 和失败率持续观测。
- 时间轴的规则联动、关系记忆和章节结局属于阶段10—12，不属于阶段9退出条件。
