# 阶层视觉令牌

阶段15共用同一组件结构。阶层差异只通过材质、线色和印记表达。这样可以避免四套界面逻辑并行分叉。

## 当前启用

| 出身 | 社会位置 | 纸张 | 结构线 | 强调 |
|---|---|---|---|---|
| 西市商户家户 | 平民 | 暖砂账纸 | 棕墨线 | 朱砂 |
| 工匠家庭学徒 | 平民 | 粗麻暖纸 | 深棕线 | 暗朱 |
| 京兆基层文书 | 胥吏 | 官抄米纸 | 靛蓝线 | 朱批 |

实现令牌：

```css
--class-paper
--class-line
--class-accent
```

## 未启用

品官、世族和帝王令牌只保留在设计研究中。没有对应玩法和史料数据前，不写入生产组件。尤其不能用明黄、龙纹或玉玺让胥吏界面暗示官位。

## 通用令牌

- `--paper`：阅读面；
- `--ink`：权威结构与正文；
- `--cinnabar`：警告、当前状态和批注；
- `--brass`：焦点、日结与不确定性；
- `--line`：一般分隔。

史料分类、出版状态和地理不确定性使用独立字段。颜色不能把三者合并成一个“可信度分数”。

## 禁止项

- 粒子、炫光和弹跳；
- 把纹理当作历史证据；
- 为填满面板添加示例物品或 NPC；
- 不同阶层使用不同交互语法；
- 仅靠颜色传达风险或状态。
