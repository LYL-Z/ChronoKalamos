# ChronoKalamos 精品垂直切片章程

## 产品目标

在742年长安完成一段约10分钟的历史人生体验。用户应能理解自己是谁、正在面对什么、选择会改变什么，以及哪些内容来自史料、哪些内容属于重建或叙事连接。

## 明确边界

- 时代固定为742 CE。
- 地点固定为长安及现有证据地点。
- 出身固定为商户家庭、工匠学徒、京兆基层吏员家庭。
- 用户可调整姓名、性别和有限性格标签，但不能自由覆盖时代、地点和社会边界。
- DeepSeek不创建世界事实，不直接写入数据库。
- 地图继续是证据索引，不是742年长安测量复原图。
- 外部学者审阅前，新增历史内容只能以 `provisional` 状态发布。

## 体验原则

1. 首次选择应在90秒内出现。
2. 选择必须在后续回合产生可见后果。
3. 回合结束必须展示状态变化、来源和未解决风险。
4. 任何失败都要说明“本回合未提交”，并提供恢复路径。
5. 未实现能力必须显示“筹备中”，不能伪装成可用功能。

## 发布顺序

`审查基线 → 十分钟上手 → 规则后果 → 内容包 → UX硬化 → 生产硬化 → 小规模测试`

任何阶段的退出条件未满足时，不得进入第二历史场景或真实商业化。
