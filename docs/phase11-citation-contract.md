# 阶段11引用合同

日期：2026-07-28

## 计数口径

阶段11当前目标是100条 `event → source` 链接。它不是100部独立著作，也不是100项相互独立的证据。

- 来源台账：18条，位于 `sources.json`。
- 实际进入事件链接的独立来源：11条；其余台账条目用于许可、排除或待核记录。
- 候选事件：27个。
- 事件—来源链接：100条，由 `phase11-citations.ts` 计算并校验。
- 公开状态：全部 `provisional`。

重复使用同一部城市史或制度史著作，不会增加独立书目的数量。它只记录该著作在哪些事件中限定了可写范围。

## 三种链接范围

| 范围 | 可支持内容 | 不可支持内容 |
|---|---|---|
| `event-context` | 编辑事件直接声明的历史背景 | 虚构人物确实说过或做过某事 |
| `claim-support` | 事件所引用 HistoricalClaim 的最小结论 | 把制度规范等同于具体执行 |
| `scene-setting` | 地点与空间语境、不确定性 | 精确铺面、道路、室内布局或镜头动作 |

## 生成规则

1. 先纳入事件原有 `evidenceRefs`。
2. 再纳入事件声明的全部来源。
3. 最后补充少量地点来源，使三条出身线的链接分布为37、32、31。
4. 同一事件和同一来源只能形成一个链接。
5. 所有链接必须指向 `sources.json` 中存在的来源。
6. 每个事件至少有三条链接。
7. 所有链接在外部历史审阅前保持 `provisional`。

## 已知局限

100条链接不能补足个案证据缺失。工匠线与基层吏员线仍主要依赖制度史和城市史。S-003、S-008、S-015、S-016、S-018还缺逐条页码或卷次。外部审阅者必须逐项补核，必要时删除链接，而不是为维持100这个数字保留弱引用。
