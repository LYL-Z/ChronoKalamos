# ChronoKalamos 游戏信息架构 v3

## 桌面结构

游戏页由四个常驻区域组成：

1. 顶栏：品牌、世界时间、日行动进度、证据、存档、设置、低动态和退出。
2. 左栏：七个系统入口和当前社会位置。
3. 中央档案：当前系统的权威数据。
4. 右侧行动卷宗：叙事、选择、方向性影响披露、失败恢复和自由行动。

底栏常驻钱财、精力、健康、士气、声望与三个行动位。

这套结构提高操作密度，但不把所有信息压成一个仪表盘。当前行动仍是唯一主操作。系统入口只解释状态，不创建绕过事件规则的新操作。

## 输入映射

| 输入 | 行为 |
|---|---|
| `M` | 地图 |
| `P` | 属性 |
| `B` | 背包 |
| `R` | 关系 |
| `J` | 任务 |
| `Space` | 聚焦当前行动卷宗 |

当焦点位于输入、文本框、下拉菜单、按钮、链接、可编辑区或对话框时，全局快捷键停用。空格永远不直接提交选择。

## 响应式规则

### 1366 px 以上

维持三列。中央档案优先获得宽度。右侧行动卷宗保持 390—470 px。

### 1120 px 以下

系统导航与中央档案保留两列。行动卷宗移到下一行，选择可以横向三列排列。

### 760 px 以下

系统导航变为可横向浏览的七项栏。页面改为纵向。常驻状态栏允许自身横向滚动，但文档宽度不得超过视口。

### 390 px

系统栏、证据筛选和行动选择均保持可触控。正文不能依赖悬停。视觉检查的文档宽度必须等于视口宽度。

## 反馈优先级

1. 失败与“未提交”；
2. 日结与精力恢复；
3. 已提交回顾；
4. 方向性后果披露；
5. 装饰性材质。

动效不能改变此顺序。低动态模式关闭装饰性过渡。
