# ADR-016：先增强现有切片的反馈闭环，不扩张未核验世界

- 状态：accepted
- 日期：2026-08-01

## 问题

用户希望先补齐吸引玩家的玩法，再进行外部历史审阅。同时希望对标《皇帝成长计划》，并保留未来 18+ 内容可能性。

直接实现七阶层、全国地图、婚育、后宫、朝政和数百物品会造成三类错误：内容量被误报，规则与数据库失配，未审内容被误认成历史事实。

## 决定

Phase 16 只增强现有三出身和 27 事件的成长反馈。旬期、目标、成就、图鉴与结算账全部由已提交状态派生。它们不新增数据库写入，也不改变 AI 权限。

新史实内容继续标为 `provisional`。只有外部审阅完成后，才允许提升出版状态。成人内容建立默认关闭的服务端门禁，但不进入当前 16+ 产品。

## 后果

- 玩家获得更清楚的短期目标与反馈。
- Supabase 不需要 Phase 16 迁移，避免在历史审阅前扩大权威表面。
- 七阶层和全国系统仍是独立内容与架构项目，不能从本阶段推断完成。
- 未来成人轨道需要单独发布决策，不能通过环境变量绕过审查。
