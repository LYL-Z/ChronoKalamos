# ADR-008：先完成742年长安十分钟垂直切片

## 状态

已接受。

## 背景

当前站点的地图和证据展示已经形成产品识别度，但首次体验仍停留在“选择入口 + 原型回合”。同时扩充地图、历史场景和模型能力会放大史料许可、测试和状态一致性风险。

## 决策

把下一轮升级限制为742年长安的三条出身线。每条线先完成一段约10分钟的可重复游玩体验，再评估第二场景。

## 后果

正面影响：

- 内容审校范围可控。
- 规则、事件和来源之间的映射可以逐条检查。
- 上手、回顾和分支后果可以在真实用户测试中验证。

代价：

- 短期内不提供全球历史场景。
- 内容团队需要先完成单一场景的深度，而不是快速堆数量。
- 第二场景和付费功能必须延后。

## 不可接受的替代方案

- 先建立没有来源台账的全球地图。
- 让模型自由创建历史人物、地点或状态。
- 用“界面已翻译”代替历史内容审校。
