# ADR-015：社会位置采用并行出身，不采用线性升阶

## 状态

已接受。

## 问题

“全阶层人生”容易被误写成“平民逐级升为帝王”。这个模型不符合现有内容，也无法由 27 个事件、12 名 NPC 和 8 个地点支撑。

线性升阶还会产生三个方法问题：

1. 把极少数社会流动路径写成一般规律；
2. 把胥吏与品官混为一谈；
3. 迫使同一角色跨越没有建模的官僚、军事、财政和宗室制度。

## 决策

阶段15采用并行出身模型：

- 商户与工匠属于不同平民生活网络；
- 京兆文书线属于胥吏生活网络；
- 三条线共享状态与交互合同；
- 每条线有独立的制度权限和证据边界；
- 后续若增加品官或帝王，必须作为新的场景清单和规则包进入。

当前不新增可任意增长的“阶层值”。社会位置由出身和已发布规则解释。声望仍分为家户、市场和行政三个既有维度。

## 后果

优点：

- 不会把游戏数值伪装成历史社会学结论；
- 保持现有存档兼容；
- 可以逐条审校不同身份的制度权限。

代价：

- 当前不能宣传“从庶民到帝王”；
- 品官和帝王界面必须等待独立内容包；
- 社会流动只能由未来有来源的事件明确建模。

## 被拒绝方案

- 单一阶层经验条；
- 声望达到阈值自动升官；
- 胥吏界面直接复用品官公务；
- 仅换皮、不改变制度权限的四阶层选择器。
