# 成人内容边界

## 当前决定

公开版继续标为 16+。Phase 16 不加入成人叙事、露骨性内容、性交易玩法或未成年人相关成人内容。用户允许“按需要加入 18+”不是安全发布证据，也不能覆盖现有公开年龄承诺。

## 默认关闭

服务端变量 `MATURE_CONTENT_ENABLED` 默认值为 `false`。即使改为 `true`，以下条件缺一项也只能得到“不可发布”结论：

- 独立年龄门禁已启用；
- 未成年人排除审查已完成；
- 内容安全审查状态为 `approved`；
- 同意政策具有明确版本号。

这些变量不连接客户端，也不自动显示内容。它们只是失败即关闭的发布前检查。

## 后续最低要求

若未来单独开发成人内容轨道，至少需要：

1. 与 16+ 主内容隔离的路由、内容清单和测试数据；
2. 明确、自愿、可撤回的同意机制；
3. 禁止未成年人、胁迫、剥削和露骨猎奇化表达；
4. 隐私政策、地区可用性和托管平台政策审查；
5. 独立内容审核与误触恢复；
6. 不把现代成人叙事当作唐代社会史实。

在这些条件满足前，任何 18+ 内容都不得进入 Supabase 发布表、客户端包或公开部署。
