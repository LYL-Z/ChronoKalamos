# 玩法闭环 v2

## 核心循环

```mermaid
flowchart LR
  A[查看当前事件与旬目标] --> B[选择或描述行动]
  B --> C[规则匹配与证据检索]
  C --> D[受控叙事表达]
  D --> E[单次事务提交]
  E --> F[结算账与关系记忆]
  F --> G[图鉴、成就与目标重新计算]
  G --> A
```

图鉴、成就和目标不拥有写权限。它们只读取已经提交的 `WorldState` 和已发布史料表。这样可增加反馈密度，同时不破坏 Phase 10 的权威状态合同。

## 旬期

- 一日仍为三个行动位。
- 十个模拟日组成一个“模拟旬期”。
- 旬期只用于界面分组和目标节奏。
- 它不宣称复原唐代历法，也不产生独立时间字段。
- 第三次行动与日结仍处于同一数据库事务。

## 目标

每种出身共享三类目标，但文案按身份变化：

1. 完成三个本出身事件节点；
2. 把对应身份声望维持到 2；
3. 形成两条正向关系记忆。

目标没有隐藏奖励。达到条件只改变展示状态。若以后加入奖励，必须由编辑事件明确授予，并进入现有事务验证。

## 成就

成就覆盖首次提交、一日结算、五个事件、关系记忆、风险解决、边界内行动和章节结局。锁定成就仍显示条件，避免伪造完成度。

## 结算反馈

每次提交后比较前后世界状态。当前支持：

- 钱财；
- 精力；
- 健康；
- 士气；
- 家户、市井、行政声望；
- 持有物数量；
- 关系总变化；
- 风险钟进度。

风险上升采用负向色。其他正数采用正向色。没有变化时明确显示“没有可见数值变化”，不制造奖励动画。

## 快捷键

| 键位 | 行为 |
|---|---|
| `M/P/B/R/J` | 打开对应系统面板 |
| `C` | 打开或关闭证据图鉴 |
| `A` | 打开或关闭成就与旬目标 |
| `1–5` | 聚焦对应选择 |
| `Space` | 聚焦行动区 |

所有快捷键只导航或聚焦。它们不自动提交状态，避免键盘误触造成不可逆回合推进。
